# EduSeguimiento

## Descripción
EduSeguimiento es una aplicación educativa desarrollada en Java que permite representar el registro de alumnos y la creación de reportes individuales para documentar observaciones y estrategias de seguimiento.

## Objetivo
Aplicar los conceptos fundamentales de la programación orientada a objetos mediante un programa sencillo relacionado con el ámbito educativo.

## Funcionalidades
- Mostrar los datos de un alumno.
- Crear reportes individuales.
- Registrar una descripción de la situación observada.
- Mostrar estrategias de seguimiento.

## Clases principales

### Clase Alumno
Contiene los atributos:
- `nombre`
- `grado`
- `grupo`

Incluye un constructor para inicializar los datos y el método `mostrarDatos()` para mostrarlos en pantalla.

### Clase Reporte
Contiene los atributos:
- `descripcion`
- `estrategia`

Incluye un constructor para inicializar los datos y el método `mostrarReporte()` para mostrar la información.

### Clase Main
Contiene el método `main()`, desde el cual se crean los objetos de las clases `Alumno` y `Reporte` y se ejecutan sus métodos.

## Conceptos de programación orientada a objetos
- Declaración de clases.
- Definición de atributos.
- Constructores.
- Instanciación de objetos mediante `new`.
- Implementación y uso de métodos.

## Tecnologías utilizadas
- Lenguaje Java.
- JDoodle Online Java Compiler.
- GitHub para almacenar y compartir el código fuente.

## Ejecución
El archivo `Main.java` puede ejecutarse en un compilador de Java compatible, como JDoodle.
